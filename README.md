# shopmanagementapp

This is our mini project - "Shop management App"
An attempt to modify the classic shopmanagement but on mobile. 
The idea was to make a user friendly light weight shopmanagement app for shopowners.
Features :
 - Inventory management
 - Log sales
 - Payment status
 - Pending payment reminders
A feature we came up with to deal with pending payments , a notification system.
We used a message template to send a message to the customers,
in the backend.
The template takes customer name , phone number and pending amount as the inputs.
